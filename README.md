# Исследование: интегратор физической роботизации (Москва / Санкт-Петербург)

Проверка гипотезы: может ли начинающая компания-интегратор с бюджетом 1–3 млн ₽
найти востребованный продукт в области физической роботизации бизнес-процессов
(склады и РЦ, строительство, производство) и выйти на первый оплачиваемый пилот
за 12–18 месяцев.

Исходное техническое задание с управляющим и этапными промптами:
[`prompts/00-research-prompts.md`](prompts/00-research-prompts.md).

## Логика исследования

```
проблемные операции → применимые технологии → предварительная экономика
→ барьеры и альтернативы → конкуренты → глубокая экономика для интегратора
→ независимый стресс-тест → продукт → проверка на объекте → оплачиваемый пилот
```

До этапа 9 любой результат остаётся экономически обоснованной гипотезой.
Решение о пилоте принимается только по фактическим данным конкретной операции.

## Правила прохождения

1. **Один этап за раз.** После каждого этапа работа останавливается, результат
   фиксируется в репозитории и ждёт утверждения заказчика. Следующий этап не
   начинается без утверждения и без закрытия критических пробелов данных.
2. **Обязательный финальный блок каждого этапа:** что установлено; что остаётся
   предположением; каких данных не хватает; что может сделать вывод ложным;
   можно ли переходить дальше.
3. **Маркировка утверждений:** `[Ф]` факт с источником, `[О]` расчётная оценка
   с показанной логикой, `[В]` вывод, `[П]` предположение.
4. **Источники:** для существенных фактов — URL, дата, география. Приоритет
   первичным источникам: вакансии, тарифы, нормы выработки, каталоги, техдокументы,
   тендеры, нормативные акты, описания реальных внедрений. Реклама производителя
   не считается независимым доказательством.
5. **Запреты из управляющего промпта:** не выдумывать цены и характеристики;
   не считать дефицит работников доказательством готовности купить робота;
   не считать китайское оборудование дешёвым до расчёта полной стоимости в РФ;
   не считать паспортные 20–24 ч полезной работой без подтверждённой загрузки;
   не называть теоретически заменяемых работников реально высвобождаемыми.
6. **Для каждого вывода** ищется альтернативное объяснение и основание для отказа.
   Вывод «подходящей возможности нет» допустим на любом этапе.
7. **Воронка:** ≤12 операций → ≤15 комбинаций → ≤10 → ≤7 → ≤5 → ≤3 → 1 основной + 1 резервный.

## Методика по этапам

- **Этап 1.** Четыре параллельных исследовательских потока: склады и РЦ;
  строительство; производство; рынок труда и полная стоимость работника
  (взносы, доплаты, текучесть, подбор, аутсорсинг, травматизм). Затем синтез:
  широкий список операций → отбор ≤12 по стоимости проблемы, сменности,
  повторяемости, стандартизируемости среды и масштабу рынка.
- **Этап 2.** Потоки по классам технологий: манипуляторы и коботы; AMR/AGV;
  паллетайзеры и специализированные роботы; подъёмные ассистенты и экзоскелеты;
  строительные роботы; полуавтоматические установки. Только покупные решения
  российского или китайского происхождения с сервисом в РФ.
- **Этапы 3–5.** Диапазонные оценки, критическое опровержение, карта конкурентов
  в РФ с приоритетом Москвы и СПб.
- **Этап 6.** Единая единица результата на комбинацию; полная стоимость труда и
  решения; полезные часы = доступные × техническая готовность × загрузка;
  денежный поток отдельно от амортизации; три сценария; оборотный капитал
  интегратора. Все расчёты выносятся в проверяемую модель (`stages/06-model/`)
  с явными формулами и допущениями. Результат принимается только после
  прохождения чек-листа «Контроль этапа 6» из ТЗ.
- **Этап 7.** Отдельный агент-рецензент с чистым контекстом получает только файлы
  этапов 1–6 и инструкцию не защищать выводы предыдущего исследователя.
- **Этап 8.** Продукт для основного и резервного вариантов, бюджеты стенда и
  пилота, компетенции, самый дешёвый следующий шаг без покупки робота.
- **Этап 9.** Протокол обследования реальной операции. Проектирование пилота —
  только после получения фактических данных от заказчика; без них этап
  останавливается на протоколе.

## Ограничения среды исследования

- В этой среде доступен только веб-поиск. Прямое открытие страниц (hh.ru,
  rabota.ru, Росстат, TAdviser, СПС, сайты производителей, зарубежные каталоги)
  заблокировано сетевой политикой. Факты берутся из поисковых выдач и сводок
  по ним; полные тексты документов не прочитаны. Такие факты помечаются
  «по сниппету», а качество доказательства оценивается ниже.
- Следствие: перед утверждением каждого этапа рекомендуется вручную проверить
  3–5 ключевых источников, особенно цены и нормы выработки.
- Цены оборудования (этап 2) без доступа к каталогам будут диапазонами из
  открытых публикаций. Для этапа 6 потребуются коммерческие предложения
  поставщиков — их запрашивает заказчик.

## Открытые вопросы к заказчику

1. Режим прохождения: останавливаться после каждого этапа (принято по умолчанию,
   как требует ТЗ) или идти автономно по этапам 1–6 с остановкой перед 7 и 9?
2. Есть ли у основателя доступ к конкретным предприятиям (знакомые склады,
   стройки, заводы в Москве/СПб)? Это повлияет на этапы 5, 8 и 9.
3. Есть ли предпочтения или исключения по сегментам и технологиям?
4. Нужен ли результат в другом формате помимо markdown в репозитории?
